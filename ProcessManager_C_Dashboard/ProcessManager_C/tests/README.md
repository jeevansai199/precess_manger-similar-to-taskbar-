# Test checklist

- [ ] Build with `build.bat` from Developer Command Prompt.
- [ ] Confirm process list populates and refreshes.
- [ ] Search for `explorer.exe` or another running process.
- [ ] Pause and resume monitoring.
- [ ] Observe CPU and memory values over multiple refreshes.
- [ ] Close a process while monitoring and confirm the application remains open.
- [ ] Run without administrator rights and confirm inaccessible processes do not crash the application.
- [ ] Close the application and confirm the worker thread exits.
